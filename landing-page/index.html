Frequently Asked Questions

Does this replace Prisma Migrate?
No — it complements it. Keep using Prisma Migrate for local development. Use prisma-to-supabase when you deploy to Supabase and want Supabase-CLI-compatible migrations with RLS, Realtime and Auth helpers generated automatically.
What Prisma versions are supported?
Prisma 5.x and 6.x. The parser reads schema.prisma directly, so it stays version-agnostic.
Can I customise the generated RLS policies?
Yes. The generated policies are a sensible starting point (owner-based access). Edit the migration files before applying them, or layer on custom policies.
Does it work with Supabase Auth tables?
Yes. It excludes Supabase-managed auth schema tables and only generates migrations for your public schema.
Is the output deterministic?
Completely. The same schema always produces the same SQL. No AI involved, so no variation between runs.
